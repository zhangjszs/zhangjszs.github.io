## 项目背景

数据结构课程的配套实验,每个主题提供三个难度版本(Basic/Challenge/Rise),从基础实现逐步过渡到挑战性变体。实验同时提供 C++ 实现与 Python 可视化版本,帮助从代码和视觉两个角度理解数据结构与算法行为。

## 技术方案

- **线性表**:顺序表与单链表的学生成绩管理,含增删改查
- **栈与队列**:基础与进阶操作
- **串**:字符串基本处理
- **二维数组**:矩阵操作
- **二叉树**:前序 `#` 标记法创建,前/中/后序遍历
- **图**:邻接表存储,BFS/DFS 遍历,A\* 寻路与 Dijkstra 最短路径
- **查找**:顺序查找、非递归二分查找、除留余数法哈希表(线性探测,测试数据 `{12,160,219,522,725,9997}`)
- **排序**:冒泡、选择、插入、堆、归并、快速排序全覆盖
- **可视化**:Python matplotlib FuncAnimation 动画展示排序过程(柱状图动态变化);PyQt5 实现 A\* 寻路 GUI(20×20 网格);networkx + matplotlib 实现 Dijkstra 演示

## 成果与数据

- 8 个主题 × 3 难度 = 24+ 份源码,覆盖课程全部知识点
- 排序可视化可直观对比各算法的时间复杂度差异
- A\* GUI 支持交互式网格编辑与实时寻路演示
