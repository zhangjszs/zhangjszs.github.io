## 项目背景

围绕公开微博内容的分析需求，构建从文章与评论采集到情感、热词、传播和预警的可视化工作流。为避免演示结果与真实数据混淆，系统文档明确区分正式、实验和演示能力。

## 技术方案

- **后端**：Flask 分层服务与 SQLAlchemy 数据访问；分析管线组织数据查询、情感结果、趋势与传播摘要，提供统一 JSON API。
- **前端**：Vue 3 与 ECharts 实现情感趋势、传播路径、热词、地域分布及预警页面。
- **分析与交付**：正式链路包含 SnowNLP、词典与规则相结合的情感分析，以及报告导出；可选模型推理、多平台采集等仍标记为实验性能力。
- **数据边界**：分析响应携带来源信息；演示数据需要显式启用，不能用模拟数据冒充真实采集结果。
