## 欢迎来到我的博客

这是一篇**占位示例文章**。在 `src/content/blog/` 目录下新建 `.mdx` 文件就能发布新文章，frontmatter 支持：

- `title`：文章标题
- `description`：摘要（会显示在列表页）
- `date`：发布日期
- `tags`：标签

## 写作体验

正文使用 Markdown/MDX 语法，内置特性包括：

1. **代码高亮**（Shiki）与一键复制按钮
2. 明暗主题自适应
3. 可以在正文中嵌入自定义组件

```ts
// 代码块示例
const greeting: string = '你好，世界';
console.log(greeting);
```
