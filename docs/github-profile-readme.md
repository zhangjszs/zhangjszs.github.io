# Kerwin Zhang

Autonomous-driving student at **Hubei University of Automotive Technology** · core member of **[FSAC Team](https://github.com/HUAT-FSAC)** (Formula Student Autonomous China), working on **perception and planning**.

- **Focus** — LiDAR ground segmentation (RANSAC + region-wise modelling), cone detection & Euclidean clustering, cost-map path planning, EKF localisation with cone-map correction
- **Stack** — C++20 · Python · ROS 1 Noetic → ROS 2 Jazzy · CUDA · PyTorch · CMake · Ubuntu 22.04
- **Engineering habits** — reproducible rosbag experiments, profiling before tuning, module boundaries kept decoupled
- **Portfolio** — every project written up with background, my role and measured results → **[zhangjszs.github.io](https://zhangjszs.github.io)** · [RSS](https://zhangjszs.github.io/rss.xml)
- **Open to** — internships and research collaboration · [zhangjszs@foxmail.com](mailto:zhangjszs@foxmail.com)
